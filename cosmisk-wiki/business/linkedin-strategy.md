## Session Learnings Log

> Add learnings from each Claude session here.

### Session 11 (May 17, 2026)
**Topic:** Memory System + Auto-wrap Orchestrator
**Learnings:**
- Option 3 (auto-wrap at call site) is cleanest for scaling 80+ agents
- Integration tests with real client data catch FK constraint issues
- Fire-and-forget pattern keeps agents non-blocking
- Memory actions can modify agent params based on learned patterns

**Post Ideas:**
- "How I wired 80+ AI agents to memory without touching their code"
- "Testing AI agents with real client data (Pratapsons case)"

### Session 10 (May 17, 2026)
**Topic:** Full Memory Wiring
**Learnings:**
- Wired 9 agents manually with consistent pattern
- Strategic context loads at function start
- Episodes recorded for significant alerts only
- Reports summarized at function end

**Post Ideas:**
- "Our agents now remember past decisions"
- "Before/after: Agents with memory vs without"

### Session 9 (May 17, 2026)
**Topic:** Memory Architecture Audit
**Learnings:**
- 95% of memory code was DESIGNED but NOT WIRED
- 45+ SQLite tables were empty
- Decay scheduler prevents memory bloat
- Client portal for HTML report viewing

**Post Ideas:**
- "I audited our AI memory — 95% was unused"
- "The difference between designing and wiring"

### Session 7-8 (May 16-17, 2026)
**Topic:** Landing Page + Quality Governance
**Learnings:**
- Quality governance must REJECT, not just log
- Instig8 "Agentic OS" aesthetic over institutional
- Terminal dark canvas (#09090B) works for AI products
- Sequential animations (GSAP + Motion) add life

**Post Ideas:**
- "Our landing page aesthetic: Agentic OS"
- "Quality gates that actually reject"
