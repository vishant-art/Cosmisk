# Additional Risks Found — 2026-04-26

## Unique essence preserved

Seven risks (A–G) beyond the original three-item audit, ordered by blast radius. Risk letters A–G here predate the renumbered A..N catalogue in the successor; the file:line refs and numbers below are the snapshot-specific detail to retain.

- **A. JWT in `localStorage` (XSS-extractable):** `src/app/core/services/meta-oauth.service.spec.ts` references `cosmisk_token` in `localStorage`; `server/src/plugins/auth.ts` issues tokens with `expiresIn: '7d'`, no jti, no refresh rotation, no revocation list. Leaked token = 7d full access; only fix today is rotating `JWT_SECRET` + forced re-login. Direction: `httpOnly`+`SameSite=Lax`+`Secure` cookie, CSRF on state-changing routes, 15–60 min access token + rotating refresh, per-user `tokenVersion` for instant revocation.
- **B. In-process cron (single-instance fragility):** 8 `cron.schedule(...)` in `server/src/routes/agent.ts`; `services/audit-scheduler.ts` builds `CronJob` inside API process. Two replicas → double-fire (billing/AI/email); one replica → missed windows on deploy/restart; crashing job destabilizes API; no central cron observability. Only `recoverInterruptedSprints()` has restart recovery. Direction: BullMQ/Redis or pg-boss/Postgres, workers in separate process, repeatable jobs, DLQ + Sentry/Slack alerts.
- **C. No retry/backoff/circuit-breaker on external APIs:** `server/src/utils/safe-fetch.ts` has timeout + AbortController only. ~13 providers: Anthropic, Gemini, Meta Graph, Google Ads, TikTok Ads, Stripe, Razorpay, ElevenLabs, Heygen, Kling, Creatify, Flux, NanoBanana, n8n, Slack, Resend. One transient 503 = hard error; degraded provider drains latency budget. Direction: exp backoff+jitter (3 attempts, 5xx+network only), per-provider circuit breaker (`opossum`/`cockatiel`), per-provider Sentry tags, idempotency keys on non-idempotent calls (Stripe charge, Razorpay capture, email send) before retrying.
- **D. God-files / decomposition debt (LOC):** `landing.component.ts` 1920 · `routes/creative-engine.ts` 1641 · `routes/ai.ts` 1371 · `server/src/index.ts` 1287 · `dashboard.component.ts` 1244 · `pitch-deck.component.ts` 1214 · `creative-cockpit.component.ts` 1133 · `settings.component.ts` 1119. Architecture-graph flags **387 cross-edges** between `routes` and `services-generate`. Direction: decompose by feature folder; start with `server/src/index.ts` and `landing.component.ts` (split into 4–6 lazy-loaded standalone components).
- **E. Cost ceilings only on creative jobs:** `server/src/services/job-queue.ts` checks daily spend before dispatch; no guard in `routes/ai.ts` (1371 LOC), `routes/agent.ts`, scoring services, or audit pipelines. Leaked JWT / runaway frontend → uncapped LLM bills; signups can burn free-tier quota. Direction: `checkAndConsumeCost(userId, provider, estimatedCents)` backed by existing `cost_ledger` table; wrap every paid-LLM route; per-plan daily cap; 429 when exceeded.
- **F. Custom column-only migrations:** `server/src/db/schema.ts` `addColumn()` shim is additive-idempotent only — no migration ledger, no rename/drop path, no down migrations, no version history. Renames silently become "add new + orphan"; Postgres cutover (Phase 2) not reproducible/rollback-able. Direction: Drizzle Kit migrations once Drizzle lands; freeze SQLite era to additive-only.
- **G. Single-replica deployment + SQLite-on-disk:** `railway.toml` `restartPolicyMaxRetries = 3`, healthcheck only; `databasePath: './data/cosmisk.db'`. Disk loss = data loss (no replication), no documented backup cadence, deploy downtime, cannot scale out (cron+SQLite combo). Resolves once Phase 2 (Postgres) ships; interim: scheduled disk snapshots, restore drill, persistent volume (verify).
