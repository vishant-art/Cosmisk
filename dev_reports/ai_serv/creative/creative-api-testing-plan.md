# Creative Studio — Full API Testing Plan (runbook)

> Prep only. Nothing here has been run. This is the plan for exercising the deployed HTTP
> surface (`apps/ai-layer/ai_layer/creative/service.py`) end to end. Two modes:
> **hermetic** ($0, mocked generation, validates the contract) and **live** (real fal spend,
> validates real generation through HTTP). Pick a mode before running (see the questions at

## The surface (9 routes, all under `X-API-Key`)

| Method | Path | Cost | What it does |
|---|---|---|---|
| POST | `/creative/generate` | paid* | static ads (all grounding on) + optional single-clip video |
| POST | `/creative/video/plan` | **$0** | script → storyboard + a cost QUOTE. Takes `creator`, `direction`, `n_shots` |
| POST | `/creative/video/generate` | **paid** | render + finish + QA + variants. Takes `creator`, `direction`, `pin_face` |
| GET | `/creative/jobs/{id}` | $0 | poll a job (status/stage/progress/assets/video/qa) |
| POST | `/creative/variants/{id}/published` | $0 | stamp `meta_ad_id` — THE join (manual) |
| POST | `/creative/learn` | $0 | harvest realized metrics → rebuild the prior (needs Meta) |
| GET | `/creative/prior/{account}` | $0 | what the account has PROVEN (variant A/B) |
| GET | `/creative/graph/{account}` | $0 | what winners CORRELATE with vs losers |
| GET | `/creative/assets/{job}/{file}` | $0 | the generated bytes (static mount) |

\* `/creative/generate` has `with_video=True` by default → a Seedance clip (~$1.22), balance-guarded and skipped if short. Set `with_video=false` for a $0-video static run.

## Mode B — live end-to-end API smoke (real spend, capped)

Start the service and drive it over real HTTP with real generation. The sequence:

```
1. POST /creative/generate {brief, with_video:false}          -> {job_id}   (brand kit, real)
2. GET  /creative/jobs/{job_id}   (poll to complete)
3. POST /creative/video/plan {job_id, seconds:10, n_shots:3,
        direction:"cozy handheld, morning light, slow"}        -> script+board+QUOTE ($0)
   # inspect the quote: clips, estimated_usd, balance, affordable
4. POST /creative/video/generate {job_id}                      -> {job_id} (PAID, ~$3.7)
5. GET  /creative/jobs/{job_id}   (poll)  -> video.url, qa.verdict, variants
6. GET  /creative/assets/{job_id}/video_captioned.mp4          -> the bytes
# the loop (no Meta -> will report "no token", still exercises the routes):
7. POST /creative/variants/{vid}/published {meta_ad_id:"..."}  -> stamp
8. POST /creative/learn {account_id}                           -> harvest+prior
9. GET  /creative/prior/{account_id}  ;  GET /creative/graph/{account_id}
```

**Cost:** step 4 is the only real charge, ~$3.67–3.70 for a 3-clip 720p video (see the
live-run doc). The plan `quote` in step 3 tells you the exact number before you pay, and the
service's own balance guard 402s if it can't cover it. A capped runner (like the one used for
the CLI live run) wraps the paid call so it physically cannot exceed a set ceiling.

**How to run the service locally:**
```bash
cd apps/ai-layer
python -m uvicorn ai_layer.api:app --port 8080
# env needed: OPENROUTER_API_KEY, FAL_KEY (+ FAL_ADMIN_KEY for the balance guard/actuals),
# SHOPIFY_STORE/TOKEN (for a real product), CREATIVE_OUTPUT_DIR (a writable dir),
# AI_LAYER_API_KEY (or leave unset for open/local mode). DATABASE_URL optional — creative
# writes are best-effort, so the job/loop tables just no-op without it.
```
The creative endpoints do NOT need the Neon test-branch `PG*` vars (those are only for the
pytest DB fixture); a plain uvicorn boot is enough.

- **Cap:** $4 hard.

**Ready, and validated at $0:**
1. Hermetic full-surface test — `apps/ai-layer/tests/creative/test_creative_api_loop.py`
   (9 tests, PASS): the loop routes (publish/learn/prior/graph) + `direction`/`n_shots`
   reaching the pipeline. With `test_creative_service.py`, all 9 routes are covered offline.
2. Live capped runner — `<scratchpad>/api_live_smoke.py` (syntax-checked, NOT run): drives
   `/creative/generate` (no smoke) -> `/creative/video/plan` (n_shots 3 + direction + creator)
   -> checks the quote <= $4 -> `/creative/video/generate` -> polls -> the loop routes. Wraps
   every paid fal call with a hard $4 guard, and writes a full TEXT record to
   `creative-api-live-run.txt`.

**Cap + "local uvicorn" note:** the runner uses in-process ASGI (`TestClient`), which is the
SAME app, routes, request/response, and real generation as a uvicorn server — the difference
is only the network socket. That in-process form is deliberate: it lets the paid providers be
wrapped so the $4 cap is HARD. A true separate `uvicorn` process cannot be wrapped from
outside, so its cap would soften to n_shots=3 + the balance guard + no-retry (~$3.7, but a QA
repair could exceed $4). If a real socket server is required, say so and I'll add a
server-side spend ceiling instead.
