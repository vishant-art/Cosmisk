# Split Deploy + Config Externalization — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split the Railway monolith into a Vercel frontend + Railway backend/ai-layer, externalize the one browser-baked config value (`API_BASE_URL`) to a Vercel env var, add a Meta-OAuth fail-safe gate, slim the backend Docker image, and document env vars — so the split deploy comes up on `feat/ai-layer-adapter` for a demo.

**Architecture:** Angular frontend (static) → Vercel with build-time config generated from a Vercel env var by an npm-hook script; Fastify API + FastAPI ai-layer → Railway with runtime env vars (already env-driven). Only `API_BASE_URL` changes category; everything else is documentation, a small UI gate, and Dockerfile cleanup.

**Tech Stack:** Angular 17, Node ESM script, Fastify, Docker, Vercel, Railway, Neon Postgres.

## Global Constraints

- Branch: `feat/ai-layer-adapter`. Do NOT merge to main. Do NOT `git push` without explicit per-instance user permission.
- Commit messages: conventional, concise, **no AI attribution / no `Co-Authored-By`** (Cosmisk rule).
- Config classification: **only `API_BASE_URL` migrates** (constant → Vercel-env-sourced build-time). `META_APP_ID` stays a committed constant. `META_OAUTH_ENABLED` is a committed default `true`, overridable by an optional Vercel env var.
- Reuse, do NOT recreate: CORS is already wired (`apps/api/src/config.ts:76-85` + `index.ts:79`); the root `vercel.json` already supplies `buildCommand`, `outputDirectory`, `framework: angular`, and the SPA rewrite. Vercel **Root Directory = repo root** (NOT `apps/web`).
- `env-config.ts` is **gitignored + generated** (Approach B); `env-config.default.ts` is the committed source of defaults.
- Backend test invariant must stay green (unaffected by this work): default suite **400/9**, pg suite **388/10**, `tsc --noEmit` baseline-only, `madge --circular` **0 cycles**.
- Dev keeps `API_BASE_URL: '/api'` (relative, dev proxy); only the **production** build externalizes it.

- [ ] **Step 2: Create the generator script**

Create `apps/web/scripts/apply-env.mjs`:

```js
// Regenerates src/environments/env-config.ts from the committed defaults,
// overriding API_BASE_URL and META_OAUTH_ENABLED from process.env when set.
// Run via the prebuild/prestart npm hooks. The generated file is gitignored.
import { readFileSync, writeFileSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import { dirname, join } from 'node:path';

const here = dirname(fileURLToPath(import.meta.url));
const envDir = join(here, '..', 'src', 'environments');
const defaults = readFileSync(join(envDir, 'env-config.default.ts'), 'utf8');

const strDefault = (name) => {
  const m = defaults.match(new RegExp(`${name}\\s*=\\s*'([^']*)'`));
  if (!m) throw new Error(`apply-env: default for ${name} not found`);
  return m[1];
};
const defApiBase = strDefault('API_BASE_URL');
const defMetaAppId = strDefault('META_APP_ID');
const defOauth = /META_OAUTH_ENABLED\s*=\s*true/.test(defaults);

const apiBase = process.env.API_BASE_URL ?? defApiBase;
const metaAppId = defMetaAppId; // public constant, never env-overridden
const oauth = process.env.META_OAUTH_ENABLED != null
  ? process.env.META_OAUTH_ENABLED === 'true'
  : defOauth;

const out = `// GENERATED by scripts/apply-env.mjs — DO NOT EDIT, DO NOT COMMIT.
export const API_BASE_URL = '${apiBase}';
export const META_APP_ID = '${metaAppId}';
export const META_OAUTH_ENABLED = ${oauth};
`;
writeFileSync(join(envDir, 'env-config.ts'), out);
console.log(`[apply-env] API_BASE_URL=${apiBase} META_OAUTH_ENABLED=${oauth}`);
```

1. **Vercel** — Root Directory = repo root; production branch `feat/ai-layer-adapter`; env vars `API_BASE_URL` = Railway Service A public URL, `META_OAUTH_ENABLED=false`. (Root `vercel.json` supplies build command, output dir, framework, SPA rewrite.)

3. **Railway Service B** — `DATABASE_URL`, `MIGRATION_DATABASE_URL`, `AI_LAYER_API_KEY` (match A); add OpenRouter/FAL manually at demo.
4. **Meta OAuth** (deferred) — once ready, add `https://<vercel-origin>/app/settings/meta-callback` to the Facebook App's Valid OAuth Redirect URIs, then set Vercel `META_OAUTH_ENABLED=true` and redeploy.
5. **Security** — rotate the leaked `ANTHROPIC_API_KEY` and Neon test-branch DB password before/at deploy.
